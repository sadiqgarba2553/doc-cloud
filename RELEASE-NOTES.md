# Doc Cloud 1.0.0 for Windows

First Windows alpha: new squircle document logo, local document library and autosave, rich text editing, editable templates, local comments and named history, native document backups and basic DOCX, text, Markdown, HTML and RTF exchange. Updated Windows build and launcher package systems. Limited Office conversion; no hosted collaboration.

Install from BlueCloud Launcher 0.7.1 or download the standalone x64 setup executable. Launcher downloads are verified against signed release metadata and SHA-256 checksums. The managed ZIP requires Microsoft WebView2, included on most current Windows systems; use the standalone installer if it is missing. No hosted account or sync service is required.

This is an unsigned alpha development release. It does not provide complete Microsoft Office compatibility. Keep native-format backups of important work. macOS/Linux builds, clean-machine installation and full native file-dialog round trips have not been verified. See docs/KNOWN_LIMITATIONS.md and docs/TEST_REPORT.md for the tested scope.

The supplied artwork is used in the app and Windows icons. Existing app identifiers and local libraries are preserved. Source code, package metadata and checksums accompany this release.

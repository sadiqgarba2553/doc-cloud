# Doc Cloud 1.1.0

Pageless drafting and continuous column previews, CSV mail merge with recipient previews and batch documents, table-of-contents snapshots, and fixes for template preservation and document layout. Existing document libraries and blue squircle branding are preserved. Advanced Office conversion and hosted collaboration remain limited.

Windows x64 alpha. Public Windows publisher signing is not available. See docs/CODEX_VERIFICATION.md for tested behavior and known limitations. Back up important work using the native file format before updating.
